Install Arduino IDE + ESP32 Board Package

Open Arduino IDE → Preferences → paste the URL below into "Additional Board Manager URLs", then install esp32 by Espressif from Board Manager.

https://dl.espressif.com/dl/package_esp32_index.json
2

Wire Piezoelectric Sensors to ESP32

Two piezo discs cover the heel and toe zones. Each connects through a signal conditioning circuit (rectifier + voltage divider) into ESP32 analog pins.

PIEZO SENSOR WIRING ────────────────────────────────── Piezo (+) → Bridge Rectifier (+) Piezo (-) → Bridge Rectifier (-) Rectifier(+) → 10kΩ → GPIO34 (ADC) Rectifier(+) → 10kΩ → 3.3V clamp diode Rectifier(-) → GND Two sensors: Heel Piezo → GPIO34 (ADC1_CH6) Toe Piezo → GPIO35 (ADC1_CH7) Battery charging: Rectifier out → TP4056 module → LiPo
3

Flash the SmartSole Arduino Sketch

Copy the full sketch below. It reads both piezo channels, detects steps from pressure peaks, calculates energy, calories & distance, then notifies over BLE every 200ms.

#include <BLEDevice.h> #include <BLEServer.h> #include <BLEUtils.h> #include <BLE2902.h> // ─── BLE UUIDs ─────────────────────────────── #define SVC_UUID "aaaa1234-aaaa-aaaa-aaaa-aaaaaaaaaaaa" #define CHR_UUID "bbbb1234-bbbb-bbbb-bbbb-bbbbbbbbbbbb" // ─── Piezo ADC pins ────────────────────────── #define PIEZO_HEEL 34 #define PIEZO_TOE 35 // ─── Thresholds & calibration ──────────────── #define STEP_THRESHOLD 800 // ADC counts (0-4095) #define STEP_COOLDOWN_MS 350 // min ms between steps #define PIEZO_VCC 3.3f // volts #define PIEZO_LOAD 10000 // ohms (load resistor) #define STEP_LENGTH_M 0.78f // avg stride metres #define CAL_PER_STEP 0.04f // kcal per step // ─── BLE objects ───────────────────────────── BLEServer* pServer = nullptr; BLECharacteristic* pChar = nullptr; bool devConn = false; // ─── Step & energy state ───────────────────── int stepCount = 0; float energymWh = 0.0f; unsigned long lastStepMs = 0; bool inStep = false; // ─── Energy calculation from peak voltage ──── float calcEnergy(int adcRaw) { float v = (adcRaw / 4095.0f) * PIEZO_VCC; float pW = (v * v) / PIEZO_LOAD; // Watts float dtS = STEP_COOLDOWN_MS / 1000.0f; // seconds return (pW * dtS * 1000.0f); // mWh approx } class ConnCB : public BLEServerCallbacks { void onConnect(BLEServer* s) { devConn = true; } void onDisconnect(BLEServer* s) { devConn = false; BLEDevice::startAdvertising(); } }; void setup() { Serial.begin(115200); analogReadResolution(12); // 12-bit ADC analogSetAttenuation(ADC_11db); // 0-3.3V range // BLE init BLEDevice::init("SmartSole"); pServer = BLEDevice::createServer(); pServer->setCallbacks(new ConnCB()); BLEService* pSvc = pServer->createService(SVC_UUID); pChar = pSvc->createCharacteristic( CHR_UUID, BLECharacteristic::PROPERTY_NOTIFY ); pChar->addDescriptor(new BLE2902()); pSvc->start(); BLEAdvertising* pAdv = BLEDevice::getAdvertising(); pAdv->addServiceUUID(SVC_UUID); pAdv->setScanResponse(true); pAdv->start(); Serial.println("SmartSole ready — advertising BLE"); } void loop() { int heel = analogRead(PIEZO_HEEL); int toe = analogRead(PIEZO_TOE); int peak = max(heel, toe); // dominant signal unsigned long now = millis(); // ─── Step detection via pressure peak ─────── if (peak > STEP_THRESHOLD && !inStep && (now - lastStepMs) > STEP_COOLDOWN_MS) { stepCount++; energymWh += calcEnergy(peak); lastStepMs = now; inStep = true; Serial.printf("STEP %d | heel=%d toe=%d | E=%.4f mWh\n", stepCount, heel, toe, energymWh); } if (peak < STEP_THRESHOLD * 0.5f) inStep = false; // ─── Derived metrics ───────────────────────── float calories = stepCount * CAL_PER_STEP; float distKm = (stepCount * STEP_LENGTH_M) / 1000.0f; // ─── BLE packet: steps,cal,dist,energy,heel,toe ── if (devConn) { char buf[80]; snprintf(buf, sizeof(buf), "%d,%.2f,%.3f,%.4f,%d,%d", stepCount, calories, distKm, energymWh, heel, toe); pChar->setValue(buf); pChar->notify(); } delay(200); }

Signal Conditioning Circuit

Piezoelectric sensors produce AC voltage spikes. A bridge rectifier converts AC to DC, a voltage divider limits it to 3.3 V, and a Zener/clamp diode protects the ESP32 ADC pin from over-voltage.

Piezo disc ┌──────────┐ (+)─┤ 4×1N4148├─(+DC)─┬──┐ (-) ┤ Rectifier├─(GND) │ 10kΩ └──────────┘ │ │ 10kΩ GPIO34 │ GND Add 3.3V Zener across GPIO34-GND for protection.
5

Pair & Monitor

Power on the ESP32. In Chrome/Edge, go to the Connect tab → Scan for ESP32 → select SmartSole. All four metrics will stream live to the Dashboard, including the energy ring showing mWh harvested.
